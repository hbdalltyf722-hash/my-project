# 🛠️ مجموعة المشاريع البرمجية التطبيقية | Practical Code Showcase

مرحباً بك! يحتوي هذا المستودع على مشاريع صغيرة مخصصة لحل مشكلات حقيقية مثل إدارة المخازن، معالجة البيانات النصية، والحسابات المالية باستخدام **Python** و **JavaScript**.

---

## 📌 قائمة المشاريع الشارحة

### 1️⃣ نظام إدارة المخزون (`inventory_manager.py`)
* **اللغة:** Python 🐍
* **الوصف:** كود موجه للكائنات (OOP) يتيح للتاجر إضافة المنتجات، تحديث كمياتها، وحساب القيمة المادية الإجمالية للبضائع في المخزن.
* **الاستخدام:** مفيد لأنظمة المتاجر الإلكترونية وإدارة المستودعات.

### 2️⃣ أداة تنظيف وتحليل النصوص (`text_cleaner.py`)
* **اللغة:** Python 🐍
* **الوصف:** سكربت متخصص في معالجة النصوص وحذف المسافات الزائدة وإصلاح تنسيق الجمل مع استخراج إحصائيات دقيقة لعدد الكلمات والحروف.
* **الاستخدام:** معالجة البيانات المدخلة من المستخدمين قبل حفظها في قواعد البيانات.

### 3️⃣ حاسبة التمويل والأقساط الشهرية (`loanCalculator.js`)
* **اللغة:** JavaScript 📜
* **الوصف:** دالة رياضية تحسب قيمة القسط الشهري للتمويل بناءً على الفائدة السنوية وعدد السنوات، مع توضيح إجمالي الفائدة المستحقة.
* **الاستخدام:** واجهات مواقع البنوك وخدمات التمويل والمتاجر التي تدعم التقسيط.
